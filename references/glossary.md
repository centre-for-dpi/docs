# Glossary

**DaaS -** DPI as a Packaged Solution. A programme that packages policy, procurement, product software, configuration and training so that a country can deploy a DPI building block quickly.

**DPG -** Digital Public Good. Open-source software, open data, open AI models, open standards or open content that follows privacy and other best practices, does no harm, and helps achieve the Sustainable Development Goals.

**DPI -** Digital Public Infrastructure. Shared digital systems, built on open standards and specifications, that public and private actors can use to deliver services at population scale.

**DPI principles -** The five DPI tech architecture principles: Interoperability; Minimalist & Reusable Building Blocks; Diverse, Inclusive Innovation; Federated & Decentralised by Design; and Security & Privacy by Design.

**eLocker -** A digital store where a person keeps the credentials issued to them and shares them with consent. An eLocker holds credentials for the holder; it does not issue them.

**mdoc -** The ISO/IEC 18013-5 mobile document format, first used for mobile driving licences. A QR code or NFC tap starts the session and the data is then exchanged between the holder's device and the verifier, usually over Bluetooth Low Energy.

**SD-JWT VC -** Selective Disclosure JSON Web Token Verifiable Credential. An IETF credential format that lets the holder reveal only the claims a verifier needs.

**SDK -** A software development kit (SDK) is a set of software tools and programs provided by hardware and software vendors that developers can use to build applications for specific platforms.

**VC -** Verifiable Credential. A tamper-evident, digitally signed credential, such as a certificate or licence, whose issuer and integrity anyone can check, often without contacting the issuer.
